# 컨텍스트 엔지니어링 필드 가이드 치트시트 2026

> 프롬프트 엔지니어링을 대체하는 2026년 핵심 스킬 — AI 에이전트 신뢰성의 90%는 컨텍스트 품질이 결정한다

## 컨텍스트 vs 프롬프트

| 구분 | 프롬프트 엔지니어링 | 컨텍스트 엔지니어링 |
|------|------------------|------------------|
| 초점 | 질문/지시 문구 최적화 | AI가 접근하는 정보 환경 설계 |
| 범위 | 단일 요청 | 세션 전체, 레포 전체 |
| 지속성 | 휘발성 | CLAUDE.md, 메모리 파일로 영속 |
| 효과 | 단발 품질 개선 | 에이전트 전체 신뢰성 향상 |

## 5가지 컨텍스트 레이어

```
레이어 5: 시스템 프롬프트 (모델 기본 동작)
    ↓
레이어 4: CLAUDE.md / AGENTS.md (프로젝트 규칙)
    ↓
레이어 3: 대화 히스토리 (세션 내 기억)
    ↓
레이어 2: 관련 파일 (코드/문서 컨텍스트)
    ↓
레이어 1: 현재 태스크 (즉시 지시)
```

## CLAUDE.md 필수 섹션

```markdown
## 프로젝트 개요
[AI가 코드베이스를 즉시 이해할 수 있는 3~5문장]

## 기술 스택
- 언어/프레임워크 버전
- 주요 의존성
- 빌드/테스트 명령어

## 코딩 규칙
- 네이밍 컨벤션
- 금지 패턴
- 필수 패턴

## AI 작업 가이드라인
- 허용 자율 범위
- 반드시 확인받아야 하는 상황
- 출력물 검증 기준
```

## 컨텍스트 품질 지표

| 지표 | 낮음 | 높음 |
|------|------|------|
| 반복 질문 수 | 5회 이상/세션 | 1회 이하 |
| 에이전트 재시도 | 3회 이상 | 1회 이하 |
| PR 리뷰 댓글 | 10개 이상 | 3개 이하 |
| 첫 시도 통과율 | 30% | 70% 이상 |

## 컨텍스트 오염 감지

오염 징후:
```
- AI가 이전 결정과 모순된 코드 생성
- 프로젝트 규칙을 무시하기 시작
- 이미 논의한 내용을 다시 물어봄
- 코드 스타일이 세션 후반부터 바뀜
```

대응법:
```bash
# 세션 초반 컨텍스트 명시적 주입
# CLAUDE.md 내용을 세션 시작 시 참조
cat CLAUDE.md | claude code "이 프로젝트 규칙을 먼저 숙지해줘"

# 장시간 세션에서 중간 리셋
/clear  # Claude Code 세션 리셋 후 CLAUDE.md 재주입
```

## 상황별 컨텍스트 설계

### 신규 기능 추가
```markdown
현재 상황:
- 기존 인증 모듈: auth/jwt.ts
- 사용 중인 패턴: Repository 패턴
- 테스트 위치: __tests__/

추가할 기능:
- OAuth 소셜 로그인 (Google, GitHub)
- 기존 JWT 인증과 병행

완료 기준:
- 기존 테스트 유지
- OAuth 플로우 단위 테스트 80% 이상
```

### 버그 수정
```markdown
버그 상황:
- 증상: [구체적 에러 메시지]
- 재현 조건: [단계별 재현법]
- 영향 범위: [관련 파일 목록]
- 시도한 수정: [이전에 시도한 것]
```

### 리팩토링
```markdown
리팩토링 범위:
- 대상 파일: [파일 목록]
- 금지: 외부 API 시그니처 변경
- 허용: 내부 구조 변경
- 검증: 기존 테스트 전부 통과
```

## 팀 컨텍스트 공유 패턴

```bash
# 팀 공통 CLAUDE.md 관리
git add CLAUDE.md
git commit -m "chore: update team AI context"

# 프로젝트별 컨텍스트 상속
# 루트 CLAUDE.md → 서브모듈별 CLAUDE.md 오버라이드
```

## 컨텍스트 비용 최적화

| 전략 | 효과 | 방법 |
|------|------|------|
| 캐시 브레이크포인트 | 비용 40~60% 절감 | 시스템 프롬프트를 요청 최상단에 |
| 불필요 파일 제외 | 토큰 30% 절약 | .claudeignore 파일 설정 |
| 요약 메모리 | 세션 간 비용 절감 | MEMORY.md 패턴 |
| 단계별 로딩 | 첫 응답 속도 향상 | 필요 시점에 파일 주입 |
