> 구독제 vs 사용량 기반 — 팀 규모별 도구 선택과 비용 최적화 한 페이지 정리

| 도구 | 무료 | 개인 | 팀/비즈니스 | 모델 |
|------|------|------|------------|------|
| **GitHub Copilot** | ✅ (제한) | $10/월 | $19/좌석/월 | 구독제 |

## 두 가지 가격 모델 비교

### 구독제 (Subscription)
- **장점:** 예측 가능한 월 비용, 예산 관리 쉬움
- **단점:** 실제 사용량과 무관하게 고정 지출
- **적합한 상황:** 매일 꾸준히 쓰는 팀, 재무 예측이 중요한 기업

### 사용량 기반 (Usage-based)
- **장점:** 많이 쓸수록 효율 상승, 소규모 팀 유리
- **단점:** 예상치 못한 비용 급증 가능
- **적합한 상황:** 사용 패턴이 불규칙한 개발자, API 직접 연동

## 팀 규모별 권장 조합

### 개인 개발자 ($20~$50/월)
```
Cursor Pro ($20)  +  Claude Code 개인 플랜 ($25)  =  $45/월

또는:
GitHub Copilot Pro ($10)  +  Claude API (사용량)  =  $15~$40/월
```

**추천:** Cursor Pro 하나를 깊이 익히는 것이 두 도구를 어설프게 쓰는 것보다 효과적

### 소규모 팀 (5~10명, 月 $100~$500)
```
GitHub Copilot Business = $190/월 (10명)
Cursor Business = $400/월 (10명)
Claude Code Team = $200/월 (10명, 연간 계약)
```

| 조합 | 월 비용 (10명) | 특징 |
|------|--------------|------|
| Copilot Business | $190 | 낮은 진입 비용, IDE 통합 강점 |
| Cursor Business | $400 | 멀티파일 편집, 에이전트 강점 |
| Claude Code Team | $200 | 터미널 에이전트, 자율성 최강 |
| Copilot + Claude Code | $390 | 균형 잡힌 하이브리드 |

### 중대형 팀 (20명+)
- 연간 계약으로 20~30% 할인 협상 가능
- 기업 플랜에서 SSO, 감사 로그, 중앙 결제 확인 필수
- Claude Code Enterprise: 볼륨 라이선스 협의 가능

## 숨겨진 비용 주의

```
실제 비용 = 구독료 + API 초과 사용료 + 교육 시간 + 워크플로우 전환 비용
```

| 항목 | 비용 예시 |
|------|----------|
| API 직접 연동 (Claude Code 무제한 사용) | Opus 8시간/일 기준 월 수천 달러 |
| 구독 플랜 초과 토큰 | 플랜별 추가 요금 확인 필수 |
| 멀티 도구 구독 중복 | $50~$200/월 낭비 가능성 |

## ROI 계산 기준

**손익분기점:** 도구 비용 ÷ 시간당 개발 비용 = 절감해야 할 시간

```
예시 — Cursor Pro ($20/월):
- 시간당 개발 비용: $50
- 손익분기: 월 0.4시간 절감이면 본전
- 실제 효과: 주 2~5시간 절감 (50~100배 ROI)
```

## 토큰 효율 비교

| 작업 유형 | 추천 모델 | 이유 |
|----------|----------|------|
| 단순 자동완성 | GPT-4o mini / Claude Haiku | 저비용, 충분한 품질 |
| 멀티파일 리팩토링 | Claude Sonnet 4.5 | 중간 비용, 높은 품질 |
| 복잡한 아키텍처 설계 | Claude Opus 4.7 | 고비용이지만 결과 정확 |
| 테스트 생성 | Gemini 3.1 Flash | 빠르고 경제적 |

## 비용 절감 실천 패턴

### 1. 모델 라우팅
```bash
# 간단한 질문 → Haiku (비용 1/20)
# 코드 생성 → Sonnet
# 아키텍처 리뷰 → Opus (하루 1~2회만)
```

### 2. 프롬프트 캐싱 활용
```
캐시 히트 시 비용 90% 절감
CLAUDE.md를 프롬프트 앞부분에 고정 → 캐시 활용 극대화
```

### 3. 구독 vs API 임계점

| 사용 강도 | 추천 |
|----------|------|
| 월 50시간 미만 | API 직접 사용 |
| 월 50~100시간 | Pro 구독 플랜 |
| 월 100시간 이상 | Max/Unlimited 플랜 |

## 2026년 가격 트렌드

- **하락세:** Gemini 3.5 Flash GA로 고성능 모델 가격 인하 압력
- **구독 vs API 수렴:** Claude Code Team 등 구독제가 API 대비 경쟁력 확보
- **무료 티어 확대:** GitHub Copilot Free, Cline 오픈소스로 진입 장벽 낮아짐
- **기업 협상력:** 20명+ 팀은 연간 계약 시 20~35% 할인 가능
